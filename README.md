# 職業訓練校でJavaを学び、Javaとservletが動かせるようになってきたので麻雀風のゲームを作ってみた。

# 弁当雀

# システム概要
+ システム名	：弁当雀
+ 目的		：これで遊んで楽しんでほしい
+ 画面描写技術	：JSP,CSS,JavaScript
+ ターゲット	：老若男女
# 機能要件
+ 基本ルール
  おかず牌10種類各10枚、ごはん牌5種各4枚、合計120枚の牌をシャッフルし山を作る。そこから4人のプレイヤーに10枚ずつ牌を配りゲームスタート。親から時計回りに山から牌を1枚拾い、河に1枚捨てる繰り返し、あがりを目指す。あがりの条件は「ごはん牌のいずれかを2枚、おかず牌のいずれかを3種類各4枚そろえる」。あと1枚で手牌があがる状態のことを聴牌といい、その状態で自模牌や相手が捨てた牌であがった場合は「いただきます」と宣言しあがる。

+ その他ルール
  リーチ
  手牌があと1枚で揃う状態になったとき「リーチ」と宣言することで1つ役をつけることができる。リーチの状態では自模牌をそのまま捨てることしかできない。
  パクッ
  相手が捨てた牌を自分が2枚持っている場合は、「パク」と宣言してその牌を拾うことができる。拾った後1枚牌を捨て自分の後の番に移る。
# 非機能要件
+ 手牌をソート
  最初に牌が配られたとき、自模ったとき、牌を捨てたときに自分の手牌の状態がわかりやすいようにごはん牌とおかず牌をわけ、ごはんやおかずの種類で分ける。
+ 牌にそのごはんやおかずのイラストを付ける
  実際に弁当を盛り付けているように遊んでほしいので牌は絵柄にする。
+ ゲーム画面を実際の雀卓のように見せる
  麻雀をしている感じを出す。
## 苦労した点
+ 最初は自分ひとりに牌を配って自模って捨てるというものを実行していたがいざほかのプレイヤー(CPU)を実装しようとすると手番を回すための仕組みや「パクッ」をした後の流れを作るのが難しかった。
